# 001 DECLARING VARIABLES

like in most coding languages, there are ways to define variables to pull data from later. for bash, the general syntax is as follows:

```bash
name="scott"
```

variables can also contain numbers:

```bash
age=67
```

variables can be printed to the terminal via the **echo** command:

```bash
echo "${name} is ${age} years old."
```

## NOTE: variables in bash are strings by default until clarified by operators/syntax cues
