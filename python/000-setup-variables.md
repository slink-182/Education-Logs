# 000 SETUP VARIABLES

To set a variable in python, first give a good variable name followed by the data it stores.
```python
# in this example, variable is named "number" containing int "12"
number = 12
```
The first function worth knowing is print, which, as the name implies, prints to the terminal screen.
```python
name = "John Doe"

print(name)
```
Output:
```terminal
John Doe
```
